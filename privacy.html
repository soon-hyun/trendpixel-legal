1. 접근하는 정보

TrendPixel Keystore는 로그인한 계정의 구글 드라이브에서 팀이 정한 폴더(JSStudio) 안의 파일만 읽고 씁니다. 다른 파일, 메일, 연락처 등 그 밖의 정보는 열람하지 않습니다. 로그인한 계정의 이메일 주소는 어느 계정으로 인증했는지 표시하는 데만 씁니다.

2. 저장과 이용

받은 파일과 인증 토큰은 그 팀원의 컴퓨터에만 저장됩니다. 외부 서버로 보내지 않고, 팀의 영상 제작 파이프라인 설정에만 씁니다.

3. 제3자 제공

어떤 정보도 판매하거나 제3자에게 제공하지 않습니다. 광고나 분석에도 쓰지 않습니다.

4. Google API 사용자 데이터 정책

Google API에서 받은 정보의 사용과 다른 앱으로의 전송은 제한적 사용 요건을 포함한 Google API Services User Data Policy를 따릅니다.

5. 권한 철회와 삭제

권한은 Google 계정 권한 페이지에서 언제든 철회할 수 있습니다. 로컬에 저장된 토큰은 해당 파일을 지우면 삭제됩니다.
